# Week 4 - HTML & CSS Basics

This repository contains basic HTML and CSS exercises demonstrating page structure, text formatting, and styling.

## Contents

The files are located in the `week4/` directory:

- **`assignment1.html`**: A basic webpage demonstrating headings, paragraphs, links, and unordered lists.
- **`cat.html`**: A structured page about a cat ("Pochi"), showcasing image embedding (base64), ordered/unordered lists, and external stylesheet linking.
- **`cat.css`**: The external stylesheet for `cat.html`, demonstrating basic CSS selectors, floating, margin/padding adjustments, and text styling.
- **`nested.html`**: An exercise in nesting HTML lists (unordered lists inside other lists) using a course list example.
